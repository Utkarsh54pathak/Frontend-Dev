Responsive CSS Cheat Sheet

Quick reference for filters, media queries, responsive web design, and typography.

1. CSS Filters

PropertyDescriptionExample
blur()Applies a blur effect.filter: blur(5px);
brightness()Adjusts brightness.filter: brightness(1.2);
contrast()Adjusts contrast level.filter: contrast(200%);
grayscale()Converts to grayscale.filter: grayscale(100%);
hue-rotate()Rotates hue color.filter: hue-rotate(90deg);
invert()Inverts colors.filter: invert(100%);
opacity()Adjusts transparency.filter: opacity(0.5);
saturate()Increases color intensity.filter: saturate(2);
sepia()Applies sepia tone.filter: sepia(100%);
drop-shadow()Adds a shadow effect.filter: drop-shadow(5px 5px 10px gray);

2. Responsive Web Design

TechniqueDescriptionExample
Fluid LayoutUses percentage-based widths.width: 80%;
Flexible ImagesImages resize within containers.img { max-width: 100%; height: auto; }
Viewport Meta TagAdapts layout to device width.<meta name="viewport" content="width=device-width, initial-scale=1.0">
Mobile-FirstDesign for smaller screens first.Start with base CSS, then add queries.
BreakpointsChange layout at specific widths.@media (max-width: 768px) { ... }

3. CSS Media Queries

QueryApplies WhenExample
@media (max-width: 1200px)Desktop to tablet.Adjust large screens.
@media (max-width: 992px)Tablet landscape.Stack elements.
@media (max-width: 768px)Tablet portrait.Change layout.
@media (max-width: 576px)Mobile phones.Adjust text & images.
@media (orientation: landscape)Landscape mode.body { flex-direction: row; }

4. Responsive Typography

TechniqueDescriptionExample
vw UnitsScales text with viewport width.font-size: 2vw;
Clamp()Sets flexible min and max sizes.font-size: clamp(1rem, 2vw, 2rem);
Media QueriesAdjusts font size by screen size.@media (max-width: 600px) { h1 { font-size: 1.5rem; } }

5. Common Breakpoints

DeviceBreakpointUsage
Small phonesmax-width: 480pxMobile layout
Large phonesmax-width: 576pxAdjust nav & text
Tabletsmax-width: 768pxStack grid elements
Laptopsmax-width: 992pxAdjust columns
Desktopsmax-width: 1200pxStandard screen
